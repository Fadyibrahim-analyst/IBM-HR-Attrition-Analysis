Key Findings

What the data reveals

The attrition problem is concentrated — not company-wide. A handful of fixable structural conditions account for the majority of departures.

30.5%
OverTime Attrition Rate
Workers doing overtime leave at nearly 3× the rate of non-OT colleagues (10.4%). The most powerful single predictor in the dataset.
vs non-OT: 10.4% — a 3× gap
39.8%
Sales Rep Attrition
33 of 83 Sales Representatives left — nearly 2 in 5 annually. The highest rate of any role. Research Directors: 2.5%.
vs Research Director: 2.5%
$2,002
Monthly Income Gap
Median income of employees who stayed ($5,204) vs those who left ($3,202). The single most actionable compensation data point.
Stayers median: $5,204/mo
24.4%
No Stock Options
58% of employees have zero stock options — and they leave at 24.4%. Employees with any options leave at 9.4%. A high-ROI, low-cash fix.
With options: 9.4% — 60% lower
263
High Flight Risk
263 employees currently flagged across 3 simultaneous low-satisfaction signals. Identifiable, actionable, and preventable with targeted HR intervention now.
Rule: JobSat≤2 + EnvSat≤2 + OT=Yes
9–11%
Achievable Target
With targeted interventions, attrition can realistically fall from 16.1% to 9–11% — saving an estimated $3.5M/year in replacement costs.
Saving: ~$750K per 1pp reduction
SQL Queries

The queries behind the insights

13 analysis queries written in MySQL 8.0, joining raw employee data with the engineered features table. From basic aggregations to CTEs and window functions.

03_analysis_queries.sql · MySQL 8.0
-- Q3: OverTime × Attrition (Critical Driver)
-- Reveals the 3× attrition multiplier for overtime workers

SELECT
    Over_Time,
    Department,
    COUNT(*) AS head_count,
    SUM(Attrition_Binary) AS left_count,
    ROUND(AVG(Attrition_Binary) * 100, 1) AS attrition_rate_pct
FROM ibm_hr_employee_attrition ibm
JOIN employee_features ef
    ON ibm.Employee_ID = ef.Employee_ID
GROUP BY Over_Time, Department
ORDER BY Over_Time, attrition_rate_pct;
-- Q5: Satisfaction Deep Dive
-- All 5 satisfaction dimensions split by attrition status

SELECT
    Attrition,
    ROUND(AVG(Environment_Satisfaction), 2) AS avg_env_sat,
    ROUND(AVG(Job_Satisfaction), 2)         AS avg_job_sat,
    ROUND(AVG(Relationship_Satisfaction), 2)  AS avg_rel_sat,
    ROUND(AVG(Work_Life_Balance), 2)        AS avg_wlb,
    ROUND(AVG(Satisfaction_Index), 2)        AS avg_sat_index,
    ROUND(AVG(Engagement_Score), 2)          AS avg_eng_score
FROM ibm_hr_employee_attrition ibm
JOIN employee_features ef
    ON ibm.Employee_ID = ef.Employee_ID
GROUP BY Attrition;
-- Q6: High Flight Risk Employee List
-- Ordered by lowest satisfaction for HR prioritization

SELECT
    ibm.Employee_ID,
    Department,
    Job_Role,
    Monthly_Income,
    Over_Time,
    Years_Since_Last_Promotion,
    Age_Group,
    Satisfaction_Index,
    Engagement_Score
FROM ibm_hr_employee_attrition ibm
JOIN employee_features ef
    ON ibm.Employee_ID = ef.Employee_ID
WHERE High_Flight_Risk = 1
ORDER BY Satisfaction_Index ASC, Engagement_Score ASC;
-- Q12: Salary Rank Within Role
-- Window function: ranks each employee vs peers in same role

SELECT
    ibm.Employee_ID,
    Job_Role,
    Monthly_Income,
    RANK() OVER (
        PARTITION BY Job_Role
        ORDER BY Monthly_Income DESC
    ) AS Salary_Rank,
    ROUND(
        Monthly_Income / AVG(Monthly_Income) OVER (PARTITION BY Job_Role),
        2
    ) AS income_vs_role_avg,
    Attrition
FROM ibm_hr_employee_attrition ibm
JOIN employee_features ef
    ON ibm.Employee_ID = ef.Employee_ID
ORDER BY Job_Role, Salary_Rank;
-- Q13: Composite Attrition Risk Score
-- CTE + multi-factor scoring to produce Critical/High/Medium/Low

WITH Risk_Scores AS (
    SELECT
        ibm.Employee_ID,
        Department,
        Job_Role,
        Monthly_Income,
        Attrition,
        (
            CASE WHEN Over_Time = 'Yes'              THEN 2 ELSE 0 END
          + CASE WHEN High_Flight_Risk = 1          THEN 3 ELSE 0 END
          + CASE WHEN Stagnation_Flag = 1          THEN 2 ELSE 0 END
          + CASE WHEN Satisfaction_Index < 2        THEN 2 ELSE 0 END
          + CASE WHEN Monthly_Income_Band = 'Low'   THEN 1 ELSE 0 END
        ) AS risk_score
    FROM ibm_hr_employee_attrition ibm
    JOIN employee_features ef
        ON ibm.Employee_ID = ef.Employee_ID
)
SELECT *,
    CASE
        WHEN risk_score >= 7 THEN 'Critical'
        WHEN risk_score >= 4 THEN 'High'
        WHEN risk_score >= 2 THEN 'Medium'
        ELSE 'Low'
    END AS Risk_Category
FROM Risk_Scores
ORDER BY risk_score DESC;

Feature Engineering

19 columns engineered in SQL

Created via a CREATE TABLE AS SELECT statement with CASE logic, arithmetic aggregation, and window functions — all in MySQL 8.0.

📊
Satisfaction_Index
Composite score averaging all 4 satisfaction dimensions. Key predictor — leavers score 0.31 lower than stayers.
AVG(EnvSat + JobSat + RelSat + WLB) / 4.0
⚡
Engagement_Score
Combines job involvement with the satisfaction composite. Used in risk ranking and the Power BI radar chart.
AVG(JobInvolvement + SatIndex) / 2
💰
Salary_vs_Role_Avg
Window function: each employee's income relative to their role's average. Identifies underpaid individuals within peer groups.
ROUND(Monthly_Income / AVG(MI) OVER (PARTITION BY Job_Role), 2)
🚨
High_Flight_Risk
Binary flag combining 3 simultaneous risk signals. 263 employees flagged — the actionable intervention list for HR.
JobSat≤2 AND EnvSat≤2 AND OverTime=Yes OR Attrition=Yes
📉
Stagnation_Flag
Flags employees who haven't been promoted in 5+ years and are still at lower job levels — early burnout signal.
YearsSinceLastPromo ≥ 5 AND JobLevel ≤ 2
🏷️
Band & Group Columns
Age_Group, Monthly_Income_Band, Tenure_Group, Career_Stage, Distance_Band, Manager_Tenure_Group — all via CASE WHEN for segmentation.
CASE WHEN [range] THEN 'label' END
Business Recommendations

3-horizon action plan

Grounded in the data, structured for non-technical stakeholders. Estimated impact: reducing attrition from 16.1% to 9–11% saves ~$3.5M/year.

This Month — 30 Days
  • Pull the 263 High Flight Risk employee list and schedule a manager stay-interview for each one.
  • Conduct an overtime audit in Sales and R&D — identify the top 30 most-overworked employees.
  • Freeze Sales Rep backfill hiring. Investigate the 39.8% exit rate before spending on recruitment.
  • Schedule stay-interviews for all Lab Technicians. 62 have left — 197 remain at risk.
Next 1–3 Months
  • Benchmark entry-level salaries. The $3K/month floor is the threshold — above it, attrition halves.
  • Expand stock options to Level 1–2 employees. Level 0→1 cuts attrition from 24.4% to 9.4%.
  • Set a monthly OT cap with VP-level approval for exceptions. Link OT data to manager KPIs.
  • Publish a visible career path for Sales Reps → Senior → Manager. No path = no reason to stay.
6–12 Months
  • Implement structured 90-day onboarding with mentors for all Level 1 hires. First 2 years are critical.
  • Tie 20% of manager performance score to team satisfaction and 12-month retention rate.
  • Annual promotion review mandate for all employees stagnant 3+ years. Add lateral moves as alternatives.
  • Introduce hybrid/remote flexibility for roles with far commuters — 50% attrition premium addressed directly.
